# SQLite Schema Lens

Локальный инструмент командной строки для снимков структуры SQLite и сравнения двух версий схемы. Он помогает увидеть добавленные, удалённые и изменённые таблицы, индексы, представления и триггеры.

Для работы нужен Python 3.10 или новее. Из папки проекта:

```bash
python -m pip install .
sqlite-schema-lens snapshot my.db --out before.json
sqlite-schema-lens snapshot updated.db --out after.json
sqlite-schema-lens compare before.json after.json
sqlite-schema-lens compare before.json after.json --format json --out diff.json
```

Команда `snapshot` записывает версионированный JSON: SQL определения и метаданные колонок, индексов и внешних ключей. Сравнение показывает объекты целиком, а не детальный план миграции. Код выхода сравнения: 0 — схемы равны, 1 — есть различия, 2 — ошибка ввода или выполнения. Код 0 при создании снимка означает успех.

Инструмент открывает существующую базу с SQLite URI `mode=ro`, начинает транзакцию чтения и не запрашивает строки пользовательских таблиц. SQL определений и выражения значений по умолчанию могут содержать литералы: проверяйте снимок перед отправкой другим людям. Для базы в режиме WAL SQLite может потребовать доступ к файлам `-wal` и `-shm`; снимок учитывает доступный WAL и не использует автоматически режим `immutable`.

Снимок ограничен 8 МиБ, 10 000 объектами и 100 000 записями метаданных. Системные объекты SQLite опускаются, кроме автоматических индексов ограничений. При ошибке инструмент сообщает о ней и не записывает частичный снимок. Выходной файл не должен совпадать с входом или служебными файлами базы. Проект сравнивает схему и не гарантирует корректность или совместимость миграции. Пример создания базы находится в `examples/example.sql`.

Для разработки: `python -m unittest discover -s tests -v`. Лицензия MIT.
